### Highlighted Project

## BOOTUNES – Interactive AI-Powered Reading Experience

**BOOTUNES** is an innovative web application designed to enrich the reading experience. It dynamically analyzes text content per chapter, creates context-aware summaries, generates emotional background artwork, and streams matching audio to create an immersive, multi-sensory reading atmosphere.

---

### Key Features & Functionalities

* **Context-Aware Text Summarization:** Automatically generates chapter-by-chapter concise summaries from uploaded digital books (PDF format).
* **Emotion & Sentiment Analysis:** Evaluates reading context to detect subtle emotional cues (e.g., joy, tension, melancholy).
* **Dynamic AI Art Generation:** Produces abstract watercolor background artwork tailored to the emotional tone of each chapter.
* **Atmospheric Audio Integration:** Fetches and streams audio tracks matching the chapter's mood to heighten engagement.
* **Interactive UI/UX:** A clean, responsive reader interface featuring dynamic background switches and real-time content presentation.
